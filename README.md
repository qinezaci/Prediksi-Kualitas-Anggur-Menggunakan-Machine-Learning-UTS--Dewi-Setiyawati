# Prediksi-Kualitas-Anggur-Menggunakan-Machine-Learning-UTS--Dewi-Setiyawati
Proyek ini bertujuan untuk membangun model klasifikasi yang mampu memprediksi kualitas anggur berdasarkan sifat-sifat kimiawi seperti kadar alkohol, tingkat keasaman, pH, dan sebagainya. Dataset yang digunakan adalah Wine Quality Dataset yang terdiri dari data training berlabel dan data testing tanpa label.
